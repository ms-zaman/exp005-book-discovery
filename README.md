# EXP-005 — book discovery experiment page

A temporary, disposable research artefact: 30 Bangla books, each showing the ways it can be experienced as audio
and what two sellers charge. Not a product. `noindex`. No advertising, no affiliate links, no sponsored placement.

Prices are title-level comparisons captured on a stated date; **editions may differ** and no "best price" claim is
made anywhere. Audio links point to YouTube and other public sources; no audio is hosted here.

Delete this repository when the experiment ends.
